Privacy Policy

Assistant · last updated 14 November 2026

1. Who this applies to

Assistant is a private application used by exactly one person, its developer and owner. It runs on a server controlled by that person. It is not distributed or offered to anyone else.

2. What data the app accesses

With the owner's explicit consent via Google sign-in, Assistant requests these Google Calendar permissions:

  • calendar.events – read the owner's calendar events and create, change or delete events on request,
  • calendar.calendarlist.readonly – list the owner's calendars (names, colors, time zone),
  • calendar.app.created – create and manage the app's own secondary calendar “Assistent”.

It accesses event data such as title, time, location, description and attendees, only from the owner's account.

3. How the data is used

  • to display the owner's events in the owner's private dashboard,
  • to create reminders and events (deadlines, travel times, appointments) when the owner asks for it,
  • to keep a local backup (ICS export) of the owner's calendar on the owner's server.

Event data may be processed by a language model that runs locally on the same server. No calendar data is sent to third-party AI services.

4. Storage and security

Data is stored only on the owner's private server, which is not publicly reachable (access only through a private VPN). Access tokens are stored in a file readable only by the server user and are never logged. The owner can revoke access at any time at myaccount.google.com/permissions or disconnect in the app, which deletes the stored tokens.

5. Sharing

Google user data is not sold, not shared with any third party, not used for advertising, and not used to train AI models. It is not transferred to anyone except as required by law.

6. Google API Services User Data Policy

Assistant's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Retention and deletion

Data is kept only as long as the owner uses the app. Disconnecting the Google account deletes the tokens; the owner can delete all locally stored calendar data at any time.

8. Contact

Questions: via github.com/AchtHaare or the support email shown on the Google consent screen.

Kurzfassung auf Deutsch

Mit Zustimmung liest und schreibt die App den eigenen Google-Kalender (Termine anzeigen, Erinnerungen anlegen, eigener Kalender „Assistent“, lokale Sicherung). Daten bleiben auf dem Server, werden höchstens von einer lokal laufenden KI verarbeitet, nicht verkauft, nicht weitergegeben, nicht für Werbung oder KI-Training genutzt.
