Assistant

A private, self-hosted personal assistant for a single user.

Assistant is a personal tool that runs on its owner's own server. It is not offered to the public and has no other users. It connects to the owner's Google Calendar in order to:

  • show upcoming events in the owner's private dashboard,
  • create events and reminders (e.g. deadlines, travel times) on the owner's request,
  • keep its own calendar named “Assistent” for entries it creates.

No data is sold, shared, or used for advertising. See the Privacy Policy.
